# Swiggy vs Zomato Restaurant Analytics

A complete Data Analytics Project analyzing restaurant performance across Swiggy and Zomato using Python, MySQL, and Power BI.

The project explores revenue, profit, orders, restaurant types, cuisines, ratings, and city-wise performance through data analysis and interactive dashboards.


# Project Overview

This project follows a complete Data Analytics workflow:

- Data Cleaning
- Feature Engineering
- Exploratory Data Analysis (EDA)
- SQL Business Analysis
- Interactive Power BI Dashboard

 # Key Insights

- Mumbai generated the highest overall revenue.
- Casual Dining restaurants contributed the highest revenue.
- Swiggy and Zomato showed similar overall performance.
- Restaurant ratings were consistently above 4.
- Revenue varied significantly across restaurant types and cities.
